Dieses Dashboard ist umgezogen 👋

Aus Sicherheitsgründen (GitHub- & Gemini-Zugangsdaten lagen hier ungeschützt im Browser) läuft die Berichtsheft-App jetzt als eigenständige Web-App unter /web im Repository, gedacht für ein Hosting auf Vercel. Alle Zugangsdaten liegen dort ausschließlich serverseitig als Environment Variables.

Trage dir die Adresse deines Vercel-Deployments hier ein und öffne sie – am besten direkt über „Zum Home-Bildschirm hinzufügen" für ein natives iOS-Gefühl.

Setup-Anleitung: siehe web/README.md im Repository.
